What you'll be able to do afterwards

  • Build multi-stage Docker images and cross-compile them for arm64
  • Explain the Kubernetes object model and ship workloads with Deployments & Services
  • Navigate a real 11-service microservice system (Go, .NET, Java, Node, Python)
  • Authenticate to an EKS-style cluster via IAM and read the token flow
  • Push and pull from a container registry and debug registries
  • Observe, load-test, troubleshoot, and tear down a live deployment

Get the lab running

git clone https://github.com/RaikaSurendra/floci-microservices-online-boutique.git
cd floci-microservices-online-boutique
cd eksSetup && ./scripts/setup-eks.sh
cd ../onlineBoutique
source scripts/00-env.sh
scripts/01-fix-eks-auth.sh && scripts/01-fix-floci-network.sh
scripts/02-clone-upstream.sh && scripts/03-build-push-images.sh
scripts/04-deploy.sh

Then open the shop with kubectl port-forward -n online-boutique svc/frontend-external 8080:80
